# DevOps25 – CI/CD 2026

Detta repository används för praktiska övningar i CI/CD-kursen på Nackademin.

## Lektion 1 – Git och GitHub

Under lektionen har jag:

- Skapat en egen fork av lärarens repository.
- Klonat min fork till datorn.
- Skapat och aktiverat en virtuell Python-miljö.
- Kört fem automatiserade tester med Pytest.
- Startat FastAPI och testat `/health` och `/add`.
- Skapat en egen Git-branch för dokumentationsövningen.

Syftet med övningen är att förstå hur Git används för att spåra ändringar och hur detta hänger ihop med CI/CD.
